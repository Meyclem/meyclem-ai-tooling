# Documentation

| Section                    | What it is                                                              | Read when                                                            |
| -------------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------- |
| [Tutorials](./tutorials/)  | Step-by-step lessons that take you from zero to a first success.        | You have never installed a plugin from here and want to see it work. |
| [How-to guides](./how-to/) | Short recipes for specific tasks.                                       | You know the basics and need to get something specific done.         |
| [Reference](./reference/)  | Exhaustive description of policies, manifests, and lifecycle behaviour. | You need to look up exact behaviour or policy.                       |

## Where to start

**First time here**

- [Get started](./tutorials/get-started.md) — register the marketplace, install
  a plugin, invoke it, and turn on auto-update.

**Contributing**

- [CONTRIBUTING.md](../CONTRIBUTING.md) — setup, plugin structure, testing, pull
  requests.
- [Quality bar](./reference/quality-bar.md) — what a plugin must satisfy.

**Operating the marketplace**

- [Lifecycle](./reference/lifecycle.md) — how updates and removals propagate,
  and how to roll one back.
- [How to remove a plugin](./how-to/remove-a-plugin.md) — stop distributing a
  plugin.

## Scope

These pages cover the **marketplace** — installing from it, contributing to it,
and how changes reach consumers. Each plugin documents itself in
`plugins/<name>/README.md`: what it ships, how to invoke it, and its limits.
